Scareware SCENARIO_03

Scareware Browser Popup

Scareware uses fake virus alerts to frighten victims into calling fraudulent numbers or downloading malicious software — while they're just browsing normally.

Identified red flags
🔍 5 red flags in this popup
1
Browsers cannot detect viruses This is the most important fact: a web browser has no ability to scan your computer for malware. Any browser popup claiming to detect viruses is 100% fake.
2
Microsoft never alerts via browser Microsoft communicates through Windows Security Centre (a desktop app), not browser popups. Any browser popup claiming to be from Microsoft is fraudulent.
3
Phone number in a security alert Real antivirus software never asks you to call a phone number. That number connects to scammers who charge hundreds for fake services or install actual malware remotely.
4
"Do NOT close this window" Closing the tab is actually the correct first step. Attackers add this warning because their popup disappears the moment you close it.
5
Specific false numbers — "5 malware infections" Attackers use specific numbers to sound credible. "5 infections" sounds more believable than "many". Specificity creates false authority.
How to respond correctly
✓ Correct actions when you see this
  • 1Do NOT call the number — it connects to scammers, not Microsoft
  • 2Close the browser tab immediately (or force-quit the browser)
  • 3Run a scan with your actual installed antivirus software
  • 4Clear your browser cache and cookies afterwards
  • 5Report the website URL to your organisation's security team
