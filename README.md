# Social Engineering Awareness Toolkit

> An interactive multi-scenario cybersecurity awareness platform that simulates real-world social engineering attacks — built for education, not exploitation.

**Live demo:** `https://sitaljungkarki-sudo.github.io/social-engineering-toolkit`

## About This Project

Social engineering is responsible for over 90% of successful cyberattacks. Unlike technical exploits, these attacks target human psychology — exploiting trust, urgency, fear, and authority rather than software vulnerabilities.

This toolkit simulates three of the most common attack vectors and teaches users to recognise and respond correctly before a real attacker gets the chance.

## Scenarios Covered

| # | Scenario | Attack Type | Techniques Used |
|---|---|---|---|
| 1 | Urgent Email Attack | Phishing | Homoglyph domain, urgency, threat of loss |
| 2 | Vishing Call | Voice Phishing | Impersonation, caller ID spoofing, authority |
| 3 | Scareware Popup | Browser Scareware | Fake virus alerts, fake support numbers |

## Features

- 3 interactive attack simulations with realistic recreations
- Clickable popup simulation — responds to user actions
- 6-question awareness quiz with detailed explanations
- Red flag analysis panels for each scenario
- Correct response guides with step-by-step actions
- Zero data collection — fully static HTML/CSS/JS

## Tech Stack

- HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (Syne + Share Tech Mono)
- GitHub Pages (hosting)

## Ethical Disclaimer

This project is built strictly for cybersecurity education and awareness. No user data, credentials, or personal information is collected, stored, or transmitted at any point. All techniques documented here are publicly known and covered in CEH, CompTIA Security+, and SANS GIAC certifications.
